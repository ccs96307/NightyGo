# NightyGo 產品與交付藍圖

## 產品定位

NightyGo 是桌面圍棋對局、棋譜編輯與 AI 覆盤工作室。棋盤是視覺中心；Play、Review、Analyze、Library 是主要工作情境。棋盤材質可有個性，整體操作介面仍需安靜、清楚、容易讀棋。

## 設計基準

- 主畫面：頂部棋譜工具列；中央棋盤；右側 Tree / Analysis / Comments 工作面板；底部棋步時間軸、局面與對局控制。
- 主題：深色分析工作區與暖白淺色工作區。棋盤外觀（木、星空、夜空）和應用程式主題分開設定。
- 棋盤：保留木紋與宇宙主題；星點、座標、落子提示、最後一手與 AI 候選著要有獨立且高對比的視覺語意。
- 棋子：單一一致光源、球面明暗、接觸陰影；裝飾不降低棋形辨識度。
- 動態：落子回饋短而清晰；背景動畫緩慢、可關閉，且不得遮住棋線或造成持續干擾。
- 可用性：系統字型、高 DPI、自訂字級、鍵盤操作、可見焦點、色彩以外的狀態提示。

## 架構決策

- 保留 Python 棋規、SGF、引擎服務與應用程式邏輯，不以 C++ 重寫。
- 把介面逐步轉到 PySide6 Qt Quick/QML，讓動畫、響應式版面與圖形效果使用 Qt Quick scene graph。
- Python 以 QObject controller / model 將狀態與命令提供給 QML。
- 遷移期間保留可啟動的 QWidget fallback；避免在大量 QQuickWidget 中反覆包裝場景。先驗證 QML 中央工作區，再逐步移動整個主視窗。
- 網路、模型權重或引擎不可用時，SGF 和手動棋譜功能仍可獨立使用。

## 執行與回滾

- 每個可驗收垂直切片獨立 commit；不把未完成 UI 與模型大改混在一起。
- 每階段完成後更新此文件的狀態和實測結果。
- `game.sgf` 與 `game1.sgf` 是使用者資料，不納入清理、格式化或版本控制操作。
- AI 引擎程式與網路服務採可選設定；大型模型權重不預設下載或打包。

# NightyGo 產品與交付藍圖

## 產品定位

NightyGo 是桌面圍棋對局、棋譜編輯與 AI 覆盤工作室。棋盤是視覺中心；Play、Review、Analyze、Library 是主要工作情境。棋盤材質可有個性，整體操作介面仍需安靜、清楚、容易讀棋。

## 設計基準

- 主畫面：頂部棋譜工具列；中央棋盤；右側 Tree / Analysis / Comments 工作面板；底部棋步時間軸、局面與對局控制。
- 主題：深色分析工作區與暖白淺色工作區。棋盤外觀（木、星空、夜空）和應用程式主題分開設定。
- 棋盤：保留木紋與宇宙主題；星點、座標、落子提示、最後一手與 AI 候選著要有獨立且高對比的視覺語意。
- 棋子：單一一致光源、球面明暗、接觸陰影；裝飾不降低棋形辨識度。
- 動態：落子回饋短而清晰；背景動畫緩慢、可關閉，且不得遮住棋線或造成持續干擾。
- 可用性：系統字型、高 DPI、自訂字級、鍵盤操作、可見焦點、色彩以外的狀態提示。

## 架構決策

- 保留 Python 棋規、SGF、引擎服務與應用程式邏輯，不以 C++ 重寫。
- 把介面逐步轉到 PySide6 Qt Quick/QML，讓動畫、響應式版面與圖形效果使用 Qt Quick scene graph。
- Python 以 QObject controller / model 將狀態與命令提供給 QML。
- 遷移期間保留可啟動的 QWidget fallback；避免在大量 QQuickWidget 中反覆包裝場景。先驗證 QML 中央工作區，再逐步移動整個主視窗。
- 網路、模型權重或引擎不可用時，SGF 和手動棋譜功能仍可獨立使用。

## 執行與回滾

- 每個可驗收垂直切片獨立 commit；不把未完成 UI 與模型大改混在一起。
- 每階段完成後更新此文件的狀態和實測結果。
- `game.sgf` 與 `game1.sgf` 是使用者資料，不納入清理、格式化或版本控制操作。
- AI 引擎程式與網路服務採可選設定；大型模型權重不預設下載或打包。

## 早期桌面版驗收紀錄

- 初版曾依 18 個項目驗收。中央工作區提供原有穩定棋盤與可切換的 Qt Quick/QML 棋盤原型；QML 資源已納入 wheel。
- Play／SGF：棋規和 9/13/19 棋盤、undo/redo、分支及主線編輯、棋局資訊、註解、棋盤標記、SGF 字元集相容與 UTF-8 正規化、原子保存、重複保存均已覆蓋。
- Analyze／Review：非同步 GTP/KataGo 連線、候選著、勝率／目差、ownership 棋盤疊圖；整盤沿主線分析、勝率圖、重大波動清單和跳轉棋步均可使用。引擎需由使用者在設定中指定本機 KataGo 執行檔與模型參數。
- Library／Recovery：近期 SGF、棋手／賽事／結果／標籤搜尋、標籤管理、未保存提示與自動復原快照已完成。
- 視覺與可用性：深色和暖白主題、可調字級、加大控制項、鍵盤焦點樣式、棋盤動畫開關；現有木紋／星空材質和球面棋子繪製保留。
- 驗證：33 項 unittest 全通過；QML offscreen 載入與 Widgets 主窗離屏啟動通過；QML wheel 資源檢查通過；假 GTP 整盤覆盤 3 個局面並檢出重大勝率波動；SGF 重複保存端到端檢查通過；`uv build` 成功。
- 限制：環境未配置真實 KataGo 執行檔和模型，AI 驗收以協定相容的假 GTP 程序加 parser tests 執行；Qt Quick 效能目前完成渲染啟動檢查，尚無跨 GPU 的正式基準測試。大型模型不下載或打包。


## 2026-11-28 跨版本稽核

| 使用情境 | 已有能力 | 待補項目或使用限制 |
|---|---|---|
| 局面分析 | 桌面與網頁都可在落子後繼續更新。網頁可點選候選手查看勝率。 | 網頁每輪對候選手重新搜尋，再依 visits 彙總結果。尚未保留同一棵持續加深的搜尋樹，也沒有把引擎回傳的候選變化圖逐手展開。 |
| 整盤覆盤 | 桌面有勝率曲線。網頁可從勝率變化較大的手數跳回棋盤。 | 網頁限主線、最多 250 手，尚無逐手勝率曲線。 |
| 棋譜編輯 | 兩版均可儲存 SGF 集合及變化。網頁可於匯入時選局。 | 桌面保留集合的其他棋局，但編輯介面只開啟第一局。網頁的主線按鈕用來篩選顯示，尚無將變化升為主線或刪除整個分支的編輯指令。 |
| 規則與死活 | 網頁有概略領地、疑似死子和 AI 領地開關。 | 規則估算是啟發式判定，雙活、劫爭等未定局面仍需棋手判讀。桌面缺少網頁的規則式覆疊。 |
| 特殊局面 | 網頁可讀取含擺子和標記的 SGF。 | 網頁 AI 限一般對局與標準黑棋讓子，不能分析任意中途擺子。桌面引擎由棋面重建局面，涉及先前劫爭的著手仍需核對。 |
| 外觀與平台 | 桌面有 Widgets 工作區及 QML 棋盤預覽，網頁支援手機觸控。 | Mimi 主題、貓耳棋子與貓叫音效目前在網頁版。QML 仍是預覽工作區。 |
